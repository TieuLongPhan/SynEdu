# SynEdu · (Talktorials S00–S08)

This repo contains the SynEdu talktorials, short, reproducible notebooks with **Theory → Practical → Discussion → Quiz**.

![SynKit](https://raw.githubusercontent.com/TieuLongPhan/SynEdu/main/synedu/synedu.png)

## Quickstart
```bash
conda env create -f env/environment.yml
conda activate synedu
jupyter lab
```

Open notebooks in `talktorials/` in order (S00 → S08).

## Data
- `data/molecules.csv`
- `data/reactions_mapped.csv`

## Outputs
Each notebook writes artifacts to `synedu/S***/out/`.
