# Citation

If you use SynEdu in academic work, please cite the archived Zenodo record.

{button}`View the Zenodo record <https://zenodo.org/records/20315656>`
{button}`Download CITATION.cff <https://github.com/TieuLongPhan/SynEdu/raw/main/CITATION.cff>`

---

## Which DOI should I use?

::::{grid} 1 1 2 2

:::{card} Current release `v0.5.0`
**`10.5281/zenodo.20315655`**

This concept DOI resolves to the latest archived version. Use it unless an
exact software version is required.

+++
[Cite the latest release →](https://doi.org/10.5281/zenodo.20315655)
:::

:::{card} Historical archive `v0.1.0`
**`10.5281/zenodo.20315656`**

This version DOI identifies the `v0.1.0` archive.

+++
[Cite `v0.1.0` →](https://doi.org/10.5281/zenodo.20315656)
:::
::::

Cite the concept DOI for the project as a whole. Cite a version DOI when the
exact archived revision matters.

## BibTeX

Use the concept DOI for the current `v0.5.0` release:

```bibtex
@software{phan_boehm_2026_synedu,
  author       = {Phan, Tieu Long and Boehm, Lukas},
  title        = {SynEdu: Executable Talktorials for Graph-Based Reaction Informatics},
  year         = 2026,
  publisher    = {Zenodo},
  version      = {v0.5.0},
  doi          = {10.5281/zenodo.20315655},
  url          = {https://doi.org/10.5281/zenodo.20315655}
}
```

The repository also includes a machine-readable `CITATION.cff` file for GitHub,
Zenodo, and any citation manager that understands the Citation File Format.
