What is SynEdu?
---------------

SynEdu is a curated set of notebooks designed to bridge **chemical intuition**
and **graph-theoretic rigor**. Each talktorial is short, executable, and focused
on building reusable primitives for reaction modeling.

Quickstart
----------

1. Install SynEdu (and docs extras if needed).
2. Open a talktorial and run top-to-bottom.
3. Reuse the primitives in your own pipelines.

See :doc:`installing` for local setup instructions.
