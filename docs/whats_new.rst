Release checklist
-----------------

- Zenodo DOI is linked from the top navigation icon and the citation page.
- The Citation page contains a Zenodo-exported BibTeX entry for ``v0.1.0``.
- Funding acknowledgement includes TACsy and European Union logos.
- Long notebook pages include direct talktorial-to-talktorial navigation.
- The docs include keyboard-visible focus states and a skip-to-main-content
  link.
