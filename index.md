# SynEdu

SynEdu is a collection of executable talktorials for reaction informatics with chemical graphs, graph morphisms, atom mapping, and rule-based reaction modeling.

The documentation is built with Jupyter Book and directly integrates the notebooks in `synedu/S01` to `synedu/S10`.

## Quickstart

```bash
conda env create -f environment.yml
conda activate synedu
jupyter lab
```

Then open the talktorials in order from `S01` to `S10`.
